Ever get tired of switching between ChatGPT, Claude, and Gemini, only to realize you have to physically click different buttons or a different key combination on every site just to upload a file or start a temporary chat?

Yeah, me too and that's why we have **AI Unified Hotkeys**.

**AI Unified Hotkeys** is a lightweight browser extension that lets you set _your own_ keyboard shortcuts to perform the exact same actions across all three major AI platforms. It bridges the gap so your muscle memory actually works everywhere. 🧠⚡

## Features

- **Cross-Platform:** Works seamlessly on ChatGPT, Claude, and Gemini.
- **Smart Focus:** Start typing from anywhere on the page, and the extension instantly grabs focus, finds the text box (even through messy Shadow DOMs), and drops your cursor exactly at the end of your text.
- **Universal Incognito/Temporary Chat:** Trigger temporary or incognito chats without hunting for the UI button.
- **Quick Uploads:** Open the file upload dialog with a single keystroke.
- **Search Chats:** Quickly search through your chat history without leaving the keyboard.
- **Remove unwanted disclaimers**: Removes the "AI can make mistakes" disclaimers to give you a little extra working space.
